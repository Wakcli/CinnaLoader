# API checklist

One line per API named in `minecraft_mod_loader_api_wishlist.md`, in the wishlist's order.
Marks: `[ ]` todo · `[~]` partial · `[x]` done and verified in-game · `[-]` not applicable
(with the reason in `apis.md`). Flip a whole section with `tools/checklist.py --section N --done`.

The queue and what each section covers live in `apis.md`; the standing goal and the rules
are in `AGENTS.md`. Work top to bottom: implement, test, verify in-game, then flip.
